How a check runs

01 · FETCH

Request the page

Validates the URL, sets a timeout, and fetches the response — catching DNS failures, redirects, and non-HTML content before anything else runs.

02 · READ

Read its vitals

Parses the HTML for title, meta description, heading structure, image alt coverage, and an approximate word count.

03 · REPORT

Return the report

Packages everything into clean JSON and renders it on the page — with sensible, specific errors if anything along the way failed.
